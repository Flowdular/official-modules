# Repository artwork

`flowdular-logo.svg` is copied unchanged from `Flowdular/landing`, `public/favicon.svg`. `official-modules.svg` embeds that same mark and adds repository typography and a module diagram. It does not introduce a new logo.

Keep the original mark geometry and colors when updating these assets. The banner is editable SVG with accessible title and description and no external resources. The release-flow diagram is maintained directly in the root README as Mermaid.

`screens/` holds the screen evidence for released module versions, captured from a disposable local application with invented demo data. Name a file after the screen and its capture width, keep it small, and never commit an image containing credentials or real tenant records. The review record in `docs/reviews` that requires a screen references it.
